## Why this repository qualifies

Montreal Walking App is an open-source urban walking route planner and walk companion. It provides reusable route scoring, POI selection, provider integration, web/mobile UI, and live walk-progress patterns for developers building city walking, tourism, local discovery, and urban mobility tools. The project is actively maintained as a TypeScript monorepo with a React web prototype, Fastify API, shared domain package, Expo mobile app, tests, seeded Montreal data, and deployment tooling.

## How API credits would be used

API credits would support maintainer automation and product-quality improvements: AI-assisted route explanation generation, POI categorization checks, route-data QA, issue triage, PR review, test generation, documentation updates, release notes, and regression review for route scoring, walk metrics, and mobile UX flows.

## Why Codex helps this project

The codebase has many focused maintenance surfaces: route scoring, provider adapters, POI import, web/mobile parity, tests, and documentation. Codex can help keep changes small, reviewed, and covered by tests while accelerating open-source maintenance work.
