# Release Plan

## Alpha

Audience: internal/testers only.

Goals:

- Validate route discovery flow.
- Validate active walk mode.
- Validate save/history.
- Find map and route geometry issues.

Minimum data:

- 8–12 draft Montreal routes.

## Beta

Audience: small Montreal users.

Goals:

- Validate route quality.
- Collect feedback on route usefulness.
- Test completion/history retention.
- Test route issue reporting.

Minimum data:

- 20–30 routes.

## Public MVP

Audience: Montreal locals and visitors.

Goals:

- App store-ready experience.
- 30–50 quality routes.
- Stable active walk and save/history.
- Clear Montreal-only scope.
- Basic route issue workflow.

## Metrics to watch

- route detail open rate
- save rate
- start route rate
- completion rate
- route issue reports
- repeat usage
- saved-to-start conversion
- average route rating
- route abandonment rate
- active walk crash/error rate

## Expansion trigger

Do not expand city coverage until:

- route start rate is healthy
- completion flow works reliably
- at least 20 routes have real user feedback
- route issue rate is manageable
- route content workflow is repeatable
