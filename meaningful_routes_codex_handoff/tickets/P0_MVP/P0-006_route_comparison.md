# P0-006 — Route Comparison

## Goal

Let users compare 2–4 routes accurately.

## Tasks

- Build comparison screen/table.
- Use domain helper for comparison values.
- Add best-for labels only when justified by metrics/tags.
- Add CTA to open selected route.

## Acceptance

- Labels do not contradict metrics.
- Distances/times/stops/difficulty are shown consistently.
- Screen works with 2, 3, or 4 routes.
