# P0-009 — Active Walk Mode

## Goal

Make active walk the primary live interface.

## Tasks

- Start session from route detail.
- Show map, route line, user position.
- Show elapsed time, distance completed, distance remaining, progress percent, stops visited, next stop.
- Add pause and end controls.
- Ensure responsive browser layout with non-overlapping controls.

## Acceptance

- Controls do not overlap fixed navigation, CTAs, or mobile browser viewport controls.
- Progress updates while active.
- End opens completion screen.
- No planned metrics replace actual session metrics during active walk.
