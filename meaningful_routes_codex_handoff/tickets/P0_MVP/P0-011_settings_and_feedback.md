# P0-011 — Settings and Feedback

## Goal

Make settings clear and add route issue feedback.

## Tasks

- Units preference.
- Pace/interests preference.
- Location permission state.
- Disabled offline/premium toggles clearly marked future/unavailable.
- Route issue report flow.

## Acceptance

- Settings values are formatted.
- Disabled controls are visually connected to their labels/toggles.
- User can report a route issue from route detail/completion.
